# Glyph Portal

A responsive React + TypeScript visual experiment featuring a custom canvas-based animated glyph field.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## GitHub Pages

The GitHub Actions workflow builds the app and deploys it to GitHub Pages whenever changes are pushed to `main`.

- Repository: https://github.com/abinannd/trial
- Expected site URL: https://abinannd.github.io/trial/

## Component note

`src/components/ui/glyph-portal.tsx` is a reconstructed implementation because the original source provided for this setup was truncated. It recreates an animated portal and interactive glyph field; it is not an exact recovery of the missing source.
